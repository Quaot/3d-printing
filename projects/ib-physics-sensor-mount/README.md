# IB Physics sensor mount

![Status](https://img.shields.io/badge/status-printed-brightgreen)
![Fusion 360](https://img.shields.io/badge/Fusion_360-F3D-orange?logo=autodesk&logoColor=white)

A custom mount, modelled in Fusion 360, that held the sensors in place for an IB Physics experiment. It's a 100 mm round holder with 96 mm insert discs that locate the sensors.

## Parts

| File | Size (mm) | Role |
|---|---|---|
| `Circle V4` | 100 × 100 × 50 | Round holder |

| `Inside V2`–`V5` | about 96 × 96 × 3 | Earlier insert versions |
| `36-2mm`, `44+0mm`, `44+2mm` | about 95 × 6 × 3 | Thin test strips for checking the fit |
